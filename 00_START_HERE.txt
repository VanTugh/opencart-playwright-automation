📋 COMMON COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Run all 203 tests:
  $ pytest main.py -v --html=reports/test_report.html --self-contained-html

Run high priority only:
  $ pytest main.py -m high -v

Run by use case:
  $ pytest main.py -m registration -v  (UC_01)
  $ pytest main.py -m login -v         (UC_02)
  $ pytest main.py -m cart -v          (UC_08)
  $ pytest main.py -m checkout -v      (UC_09)

Run in parallel (faster):
  $ pytest main.py -n 4 -v

Run with verbose logging:
  $ pytest main.py -vv --log-cli-level=DEBUG

Run specific test:
  $ pytest main.py -k "TC_01_01" -v

Use interactive menu:
  $ python run_tests.py

🎓 EXTENDING THE FRAMEWORK
═══════════════════════════════════════════════════════════════════════════════

To add new handlers:

1. Create handler class:
   class UC21_NewFeatureHandler(BaseHandler):
       async def execute_test(self, test_data):
           await self.navigate_to("index.php?route=new/feature")
           return await self.verify_text("expected")

2. Register handler:
   USE_CASE_HANDLERS['UC_21'] = UC21_NewFeatureHandler

3. Add test cases to JSON

4. Run tests:
   pytest main.py -m new_feature -v

See examples.py for detailed patterns and best practices.
